# Spark Academy Odisha Website

A responsive educational website built using HTML, CSS, and JavaScript for the Spark Academy Odisha initiative.

## Features

- Responsive design for desktop, tablet, and mobile devices
- Class-wise navigation for Classes 8, 9, and 10
- Subject-wise organization:
  - Mathematics
  - Physics
  - Chemistry
  - English
- Topic-wise learning pages
- Search functionality for topics and videos
- YouTube integration section
- Founder and contact sections
- Mobile sidebar navigation

## Tech Stack

- HTML5
- CSS3
- JavaScript
